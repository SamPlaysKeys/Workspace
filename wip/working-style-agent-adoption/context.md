# Working Style Agent Adoption

**Goal:** Improve how individual AI agents adopt and follow the working style conventions defined in `workstyle/working_style.md`.

**Current state:** 
- Working style document exists and is comprehensive
- Cursor rule (`co-creation.mdc`) provides a summary for always-on reference
- Adoption varies by agent/model — some follow behaviors consistently, others need prompting
- **Draft onboarding doc in `scratch/onboarding.md`** — ready for review

**Open questions:**
- What barriers prevent consistent adoption across different agents?
- How can the working style be surfaced at the right moments without overwhelming context?
- Should there be agent-specific guidance or is universal framing sufficient?
- What's the minimum effective context an agent needs to follow the behaviors?
- How do we measure whether an agent is "following" the working style?

**Key constraints:**
- Context window limits vary by model
- Can't assume agents have memory across sessions
- Working style should remain agent/model agnostic
- Behaviors need to be invocable without reading the full document every time
