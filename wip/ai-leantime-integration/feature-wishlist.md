# Leantime Feature Wishlist — AI Agent Interaction

## Tier 1: Core Task Management (Essential)

- **List tasks** — "What are my open tasks?", "Show me tasks in the Homelab project"
- **Create tasks** — "Add a task to research Tailscale subnet routing in the Infrastructure project"
- **Update task status** — "Move task 42 to In Progress", "Mark the backup audit as Done"
- **Assign tasks** — "Assign the OAuth research task to me"
- **Set priority/effort** — "Tag the database migration as high priority, 3 story points"
- **Add/update due dates** — "Set the deadline for task 42 to Friday"
- **Filter tasks** — "Show tasks assigned to me that are due this week", "Find blocked tasks"
- **Subtasks** — "Create a subtask under task 42 for choosing an auth library"

## Tier 2: Project & Milestone Management

- **List projects** — "What projects do I have?"
- **Project overview** — "Show me the status of the Infrastructure project"
- **Create milestones** — "Create a milestone 'Q3 Infrastructure Upgrades' due Sept 1"
- **Link tasks to milestones** — "Add task 42 to the Q3 milestone"
- **Project progress** — "How far along is the Homelab project?"
- **Sprints** — "What's in the current sprint?", "Create a sprint for next week"

## Tier 3: Time Tracking

- **Start timer** — "Start tracking time on task 42"
- **Stop timer** — "Stop tracking, log 45 minutes against task 42"
- **Get timesheet** — "How many hours did I log this week?"
- **Time by project** — "Show time spent on the Infrastructure project this month"

## Tier 4: Knowledge & Planning

- **Docs** — "Summarize the network architecture doc", "Create a new doc called 'Backup Strategy'"
- **Ideas** — "Save this thought as an idea", "Show me my idea board"
- **Retrospectives** — "Create a retrospective for the current sprint"

## Tier 5: Goals & Strategy

- **List goals** — "What are my current goals?"
- **Goal progress** — "How am I tracking against my homelab reliability goal?"
- **Link work to goals** — "Connect milestone Q3 Upgrades to the 'Improve Infrastructure Reliability' goal"

## Tier 6: Reporting & Insights

- **Project reports** — "Generate a status report for the Infrastructure project"
- **Due soon** — "What tasks/milestones are overdue or due this week?"
- **Cross-project view** — "Give me a summary of everything I'm working on"

## Out of Scope (for now)

- User management / permissions
- System configuration (LDAP, plugins, etc.)
- File uploads / S3 configuration
- Canvas / Whiteboard manipulation (visual tool, hard to drive via chat)
