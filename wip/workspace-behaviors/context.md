# Workspace Behaviors

## Goal

Brainstorm additional behaviors, refinements, or related concepts for the workspace's co-creation framework.

## Current State (updated 2026-04-23)

Five behaviors defined in `workstyle/working_style.md`:
- **Storm Session** — Brainstorming in `.wip/`
- **Pre-Mortem** — Adversarial review before decisions
- **Smooth Brain** — Surface and question assumptions
- **Progressive Bookkeeping** — Keep state files current
- **Dead Drop** — Structured session handoffs (with Close-out compound behavior)

Two conventions:
- **Isolation** — No write-back to external workspaces without confirmation
- **Append, Don't Replace** — State files accumulate, don't overwrite

**Graduated (2026-04-23):** Troubleshoot behavior added to `workstyle/working_style.md`
- Structured investigation sessions for debugging external systems
- Two graduation outputs: remediation doc (always) + prevention doc (conditional)
- Quick doc path for known fixes (skip session)
