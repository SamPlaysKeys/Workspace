Strategic progression of the AI Workspace. This is a living document that evolves as the framework matures.

- [x] Repository structure and directory layout

## Phase 2: Working Style Framework ✓

*Creating portable behaviors for AI collaboration.*

- [x] **Storm Session** — Brainstorming in `wip/` with disposable sessions
- [x] **Pre-Mortem** — Adversarial review before committing to decisions
- [x] **Smooth Brain** — Surface assumptions at session start
- [x] **Progressive Bookkeeping** — Keep state files current throughout
- [x] **Dead Drop** — Structured session handoffs
- [x] **Troubleshoot** — Debug with knowledge capture, graduates to docs
- [x] **Sneaky** — Hide working files for external repo use
- [x] **Conventions** — Isolation, Append-Don't-Replace, Documentation Structure
