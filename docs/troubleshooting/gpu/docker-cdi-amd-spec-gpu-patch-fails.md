# Docker CDI "AMD spec not found" Error Patching GPU in NemoClaw

## Symptoms

- `nemoclaw onboard` fails at the GPU patch step
- Error output: `AMD CDI spec not found`
- `nvidia-smi` works on the host (GPU is detected and functional)
- `/etc/cdi/nvidia.yaml` exists but `/etc/cdi/amd.yaml` does not
- Docker containers launched with `--gpus all` may fail or fall back to CPU

## Cause

Docker's CDI (Container Device Interface) subsystem enumerates all available CDI specs from `/etc/cdi/` and `/run/cdi/`. When NemoClaw/OpenShell requests GPU passthrough, Docker's CDI resolution internally queries both NVIDIA and AMD device specs. On Proxmox GPU passthrough VMs, the NVIDIA container toolkit only generates `nvidia.yaml`; if no `amd.yaml` is present, the CDI resolution fails with "AMD CDI spec not found."

This appears to be caused by Docker's CDI looking for AMD specs as part of its device discovery — possibly because the GPU is presented via Proxmox PCI passthrough which may tag the virtual function with a generic or AMD-alike class code in certain VM configurations.

## Resolution

Create a minimal stub CDI spec for AMD so Docker's CDI resolution completes:

```bash
sudo tee /etc/cdi/amd.yaml > /dev/null <<'EOF'
---
cdiVersion: "0.5.0"
kind: "amd.com/gpu"
devices:
  - name: "stub"
    containerEdits:
      env:
        - ROCR_VISIBLE_DEVICES = ""
EOF
```

Then restart Docker:

```bash
sudo systemctl restart docker
```

If `amd.yaml` was previously generated by an incomplete install, clear `/etc/cdi/` and `/run/cdi/` and regenerate from scratch:

```bash
sudo rm -f /etc/cdi/amd.yaml /etc/cdi/nvidia.yaml /run/cdi/*.yaml
sudo nvidia-ctk cdi generate --output=/etc/cdi/nvidia.yaml
sudo tee /etc/cdi/amd.yaml > /dev/null <STUB_CONTENT>
sudo systemctl restart docker
```

## Verification

1. Confirm both CDI specs are present:
   ```bash
   ls -la /etc/cdi/amd.yaml /etc/cdi/nvidia.yaml
   ```

2. Rerun the NemoClaw GPU patch step:
   ```bash
   nemoclaw onboard
   ```
   The GPU patch should complete without errors.

3. (Optional) Test GPU access in a sandbox container:
   ```bash
   openshell sandbox run --gpus all -- nvidia-smi
   ```
