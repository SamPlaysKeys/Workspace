# Event notes

Consolidated notes from conferences, meetups, and internal events — speakers, sessions, takeaways, and follow-ups.

## Adding an event

1. Copy [`TEMPLATE.md`](TEMPLATE.md) to a new file: `YYYY-<short-event-name>.md` (kebab-case).
2. Fill in event metadata at the top.
3. Add rows to the session index as you capture talks.
4. Expand per-session sections when you have detail worth keeping.

## File naming

| Pattern | Example |
|---------|---------|
| `YYYY-<event-slug>.md` | `2026-cackalackycon.md` |
| Multi-day, same brand | `2026-company-offsite-day1.md` (only if splitting helps) |

Prefer one file per event unless size makes it unwieldy.
